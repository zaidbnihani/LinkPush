# PRD – LinkPush
### Product Requirements Document

**آخر تحديث:** 2 أغسطس 2026
**المالك:** Zaid (ZaidHB)

---

## 1. نظرة عامة (Overview)
LinkPush هو تطبيق أندرويد يتيح للمستخدمين مشاركة الروابط بين الأجهزة عبر شبكة الواي فاي المحلية مباشرة، مع خاصية اكتشاف الأجهزة القريبة على نفس الشبكة تلقائيًا — دون الحاجة لسيرفر وسيط أو اتصال إنترنت خارجي.

## 2. المشكلة (Problem Statement)
مشاركة رابط بين جهازين (نفس الشبكة، بدون إنترنت خارجي، أو بسرعة وبدون تطبيقات طرف ثالث مثقلة) غالبًا تحتاج نسخ/لصق يدوي، أو اعتماد على تطبيقات مشاركة ثقيلة (بلوتوث، تطبيقات مشاركة ملفات عامة) غير مخصصة لمشاركة روابط بسيطة وسريعة.

## 3. الهدف (Goal)
توفير طريقة فورية، آمنة، ومباشرة (P2P عبر واي فاي محلي) لإرسال رابط من جهاز إلى آخر بأقل عدد خطوات ممكن، مع اكتشاف تلقائي للأجهزة المتاحة بدل إدخال IP يدويًا.

## 4. الميزات الأساسية (Core Features)
| # | الميزة | الوصف |
|---|--------|-------|
| 1 | مشاركة الروابط عبر واي فاي محلي | إرسال رابط من جهاز إلى جهاز آخر مباشرة عبر نفس شبكة الواي فاي، دون المرور بخادم خارجي |
| 2 | اكتشاف الأجهزة تلقائيًا | فحص الشبكة المحلية وعرض الأجهزة المتاحة/المتصلة تلقائيًا لاختيار جهاز الاستقبال دون إدخال عنوان يدويًا |

## 5. خارج النطاق حاليًا (Out of Scope)
- أي مزامنة أو تخزين سحابي للروابط
- مشاركة عبر الإنترنت (خارج الشبكة المحلية)
- حسابات مستخدمين أو تسجيل دخول
- تحليلات (Analytics) أو إعلانات (Ads)

## 6. المستخدم المستهدف (Target User)
أي مستخدم أندرويد يحتاج مشاركة رابط بسرعة مع جهاز آخر (شخصي أو لمستخدم ثاني) على نفس شبكة الواي فاي، بدون الاعتماد على تطبيقات مراسلة أو إنترنت خارجي.

## 7. المتطلبات التقنية العامة (Technical Notes)
- منصة: Android (Kotlin / Jetpack Compose، حسب البنية الحالية للمشروع)
- الاتصال: شبكة محلية (Local Wi-Fi) — P2P بدون خادم مركزي
- لا توجد قاعدة بيانات خارجية أو خدمات طرف ثالث (حسب البنية الحالية)

## 8. مؤشرات النجاح (Success Metrics)
- نجاح اكتشاف الجهاز الهدف على الشبكة خلال ثوانٍ معدودة
- نجاح إرسال/استقبال الرابط دون فقدان بيانات أو انقطاع
- سهولة الاستخدام: عدد خطوات أقل من أي بديل (نسخ يدوي، بلوتوث، تطبيقات مشاركة عامة)

## 9. ملاحظات مستقبلية (Future Considerations)
> هذا القسم مفتوح للتوسعة لاحقًا — مثل دعم مشاركة أنواع محتوى إضافية، أو دعم اكتشاف عبر Wi-Fi Direct بدل الشبكة المشتركة فقط، إذا تقرر لاحقًا توسيع نطاق المشروع.
